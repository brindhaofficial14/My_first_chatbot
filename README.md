This project employs the Multinomial Naive Bayes (MNB) algorithm for intent recognition
due to it’s prowess in text classification. The present work of this chatbot also remains realtime and dynamic by integrating external APIs such as OpenWeather, CoinGecko, and
JokeAPI. The most fundamental requirement is to design an environment in which not only
the questions being asked by the user are recognized but the answers that are returned are also
appropriate.
The core of a chatbot is in NLP which handles the input and analysis of text from the user.
Even simple ways to filter the query such as tokenization and lemmatization will help to
categorise the query in the intents like the calculation, weather, or trivia. This makes certain
that depending on the question that the consumer has posed to it, the chatbot provide an
accurate response.
